# BOSS 求职降噪助手 V0.5.15

这是一个本地 Chrome/Edge 插件 V0.5.15 标注同步修复版。

当前版本做两件事：

- 在 BOSS 职位卡片下方固定显示标记按钮。
- 把已沟通、等待回复、被拒绝、不合适、稍后看、屏蔽公司、备注和 HR 名称保存到本机浏览器。
- 提供导出和导入记录。
- 在职位列表右侧详情区增加 `打开详情页沟通`，用于在新标签打开当前职位详情页；详情页内保留 BOSS 原生 `立即沟通`。
- 在消息页右侧聊天框顶部支持按 `公司 + 职位 + HR` 自动强匹配标记。
- 消息页标记后，会按公司和归一化后的岗位标题同步到职位列表的状态按钮。
- 消息页左侧列表不加文字，但会给已记录会话显示轻量颜色提示。
- 修复扩展重新加载后旧页面脚本访问 `chrome.storage` 导致的上下文失效报错。
- 修复消息页职位字段偶发识别失败导致 `被拒绝` 等状态看起来丢失的问题。
- 增强右侧职位卡片识别：会从薪资附近反推职位名。
- 修复右下角面板标题仍显示 `V0` 的问题。
- 修复 `董事长助理`、`总助`、`秘书` 等岗位在消息页被误判为缺职位的问题。
- 拆分 `未读未回` 和 `已读未回`，并增加 `已发简历`、`面试` 时间记录。
- 右下角面板显示今日/本周沟通、简历、面试统计。
- 自动识别低活跃招聘者，把 `本月活跃` 等低活跃职位标记为 `僵尸职位` 并隐藏。
- 提供独立数据面板，集中查看所有本地求职记录。
- 数据面板默认展示流程记录，支持点击汇总卡片联动筛选。
- 数据面板支持今日、昨天、最近 7 天、最近 30 天、全部等自然时间筛选。
- 数据面板汇总卡片会跟随视角变化，流程视角不再展示无关排除类指标。
- 右下角面板新增“导出页面信息”，用于检查当前页面是否存在 jobId。
- 打开职位详情页时，会自动用详情页里的 `jobId`、岗位、公司、薪资、地区和 HR 信息补齐本地记录。
- 如果消息页之前已经产生了 `公司 + 职位 + HR` 的临时沟通记录，详情页会把它合并到正式 `jobId` 记录上。
- BOSS 页面右下角面板新增“打开数据面板”，不用再回到插件弹窗里找入口。
- 数据面板流程视角只展示流程指标：总处理数、未读未回、已读未回、已沟通、已发简历、面试、被拒绝。
- 数据面板默认流程视角只展示明确流程状态，未标记职位保留在“全部职位”视角。
- 被拒绝属于流程结果，会出现在流程视角里。
- 排除/暂存视角展示不合适、僵尸职位、稍后看、屏蔽公司。
- `稍后看` 不再计入流程视角的总处理数，也不会出现在流程明细里。
- 数据面板日期默认选择“今日”。
- 数据面板会按最新标记时间合并岗位记录和消息记录的状态，避免消息页已改状态但看板仍显示旧状态。
- 过滤 BOSS 字体混淆导致的乱码薪资，避免 `��-��K` 写入或展示。
- 减少重复扫描和重复渲染，避免插件 DOM 改动反复触发自身扫描。
- 收窄僵尸职位识别范围，避免正文或标签里的“本月活跃”等文字误伤正常职位。
- 清除状态时同步清理流程统计时间，避免看板统计残留。
- 仅在顶层页面运行内容脚本，减少 iframe 重复注入和多实例写入风险。
- 监听本地存储变化，降低多个 BOSS 标签页同时打开时互相覆盖数据的风险。
- 保存前会合并浏览器里最新记录，减少旧标签页覆盖新标签页状态的风险。
- HR 名称不再作为硬匹配条件，避免手动补 HR 后导致消息页和职位页断开关联。
- 数据面板会监听本地记录变化，已打开的面板也会自动刷新。
- 职位详情页不再注入额外沟通按钮，避免详情页跳消息页时 HR 不匹配。
- 打开职位详情页补齐记录时，只合并临时记录且岗位名必须严格一致，避免把不同岗位误删误并。
- 消息页工具栏会优先展示匹配职位的最新状态，列表页修改状态后消息页也能跟随。
- `打开详情页沟通` 点击时实时读取当前选中职位，不再兜底打开列表第一条职位。
- 在 `manifest.json` 里加入固定 `key`，避免以后因为换文件夹加载而生成新的扩展 ID。

## 安装

1. 打开 `chrome://extensions/` 或 `edge://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择这个文件夹：

```text
boss-job-noise-reducer-extension
```

5. 打开或刷新 BOSS 直聘页面。

如果职位卡片下方出现标记按钮，说明插件注入成功。

## 使用

1. 打开 BOSS 职位列表页。
2. 等职位列表加载出来。
3. 在职位卡片下方点击状态按钮。
4. 已沟通会弱化展示，不会隐藏。
5. 被拒绝、不合适、屏蔽公司的职位默认折叠，可以展开或清除标记。
6. 列表右侧详情区可点击 `打开详情页沟通`，在新标签打开详情页后使用 BOSS 原生 `立即沟通`。
7. 右下角面板可以导出本地记录。

## 数据面板

点击插件弹窗或 BOSS 页面右下角面板里的“打开数据面板”，会打开独立管理页：

- 默认展示流程记录，可切换到全部职位或排除项。
- 支持按公司、岗位、HR、备注搜索。
- 支持按状态筛选。
- 支持按自然时间范围筛选，并可指定时间字段。
- 支持点击汇总卡片筛选明细列表。
- 支持按最近更新、公司、状态排序。
- 支持导出 JSON。

当前版本的数据面板先做只读管理，不直接编辑记录，避免误改已有数据。

## 僵尸职位

插件会读取页面上已经显示的招聘者活跃状态：

- 保留：`在线`、`刚刚活跃`、`今日活跃`、`3日内活跃`
- 自动标记僵尸职位：`本月活跃`、`本周活跃`、`7日内活跃`、`15日内活跃`、`30日内活跃` 等

僵尸职位会默认隐藏，可以在右下角面板关闭“自动隐藏僵尸职位”。

## 消息页标记

打开：

```text
https://www.zhipin.com/web/geek/chat
```

消息页左侧列表不展示插件信息，避免挤占原页面内容。

右侧聊天框顶部会出现一行轻量工具条：

- 插件会在点击状态按钮时重新读取当前右侧聊天框里的公司、职位和 HR。
- 三项齐全时，保存为 `公司 + 职位 + HR` 强匹配记录，并同步到对应职位记录。
- 三项缺失时不会弹出补全输入框，只提示缺失字段。
- 支持 `已读未回`、`未读未回`、`已沟通`、`已发简历`、`面试`、`被拒绝`、`不合适`、`稍后看`。
- `已发简历`、`面试`、沟通类状态会记录首次时间和最近操作时间。

当前版本只读取页面上已经显示的文本，不请求接口、不自动翻页。

## 详情页补齐

如果某条沟通是 HR 主动发起，消息列表里可能先拿不到完整岗位信息。你打开对应职位详情页后，插件会：

- 从详情页 URL 和页面链接中读取当前岗位 `jobId`。
- 从详情页读取岗位、公司、薪资、地区和 HR 信息。
- 用 `jobId` 作为正式岗位主键保存。
- 把之前消息页生成的临时记录合并到正式岗位记录上。

这样后续职位列表、消息页和数据面板会尽量指向同一条岗位记录。

## 统计口径

右下角面板会显示：

- 今日沟通 / 本周沟通：按第一次标记沟通类状态的时间统计，包括 `未读未回`、`已读未回`、`已沟通`、`已发简历`、`面试`。
- 今日简历 / 本周简历：按第一次点击 `已发简历` 的时间统计。
- 今日面试 / 本周面试：按第一次点击 `面试` 的时间统计。

同一个职位重复点击不会重复计入“首次”统计，只会更新最近操作时间。

## 升级与数据

Chrome 的 `chrome.storage.local` 按扩展 ID 隔离。本地开发版如果每次删除旧扩展、换文件夹加载新扩展，可能会得到新的扩展 ID，看起来就像数据丢了。

本版本已加入固定 `key`，后续即使换文件夹加载，也会尽量保持同一个扩展 ID。

重要：从之前没有固定 `key` 的版本升级到这个版本时，扩展 ID 可能会变化一次。已有记录请先在旧版右下角面板点击“导出记录”，升级后再点击“导入记录”恢复。

最稳妥的升级方式：

1. 不删除扩展。
2. 直接覆盖这个扩展文件夹里的文件。
3. 在 `chrome://extensions/` 里点击“重新加载”。
